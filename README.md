# 性剝削 24 小時引導評估工具

兒少性剝削案件 24 小時必要安置評估的現場判別輔助工具。引導第一線社工從案件性質分流、法定觸發、危機覆判到評估小結,逐步釐清「安置／督導確認／帶回／轉介」與「列為保護個案與否」,並產出可貼用的文書草稿。

## 用途與定位

本工具為**現場判別輔助**,協助結構化思考與決策,**不取代**專業評估、督導確認與正式核對表填寫。所有閾值與判定為引導性質,最終判斷仍由社工與督導為之。

## 功能

- **STEP 1　案件性質與分流**:案件型態(實體／數位／兼具)、性剝削屬性判別(內容門檻＋剝削要素)、兒少當前狀態(在家／已安置／感化)、競合與減述標記
- **STEP 2　法定觸發**:24 小時必要安置指標勾選,含灰區項目判別重點;返家可行性判別(含同儕加害人、安全計畫成效)
- **STEP 3　危機覆判**:人身安全紅旗、家長因素翻盤檢核、處遇與後追參考
- **STEP 4　數位風險(IBSA)**:接觸／擴散／衝擊三軸補充
- **STEP 5　評估小結**:綜合結論(處置方向＋列為保護個案與否)與文書草稿

指標 5「對剝削者／色情業高度認同」附互動判別:以行為深度與「關鍵區辨(恐懼／依附／發展／內化)」降低主觀評分變異;勾選該指標前須先完成判別。

## 資料治理

- **純前端、單一 HTML 檔**,無任何外部相依套件。
- **不蒐集、不傳輸、不上傳任何資料**:所有勾選與輸入僅留在使用者瀏覽器當下,關閉即消失,無雲端回傳。
- 文書草稿於畫面內產生,供使用者自行複製、編輯。

## 使用方式

直接開啟 `index.html` 即可使用,亦支援手機瀏覽器。無需安裝、無需連線。

## 依據

- 衛福部／台灣展翅《兒少性剝削防制新法工作手冊》24 小時指標、附錄四(廖美蓮)
- 《數位網路兒少性剝削工作手冊》
- 《兒童及少年性剝削防制條例》§2;刑法 §10 性影像定義
- 兒童權利公約(CRC)相關條文

STEP 3 翻盤檢核為附錄四家長因素之操作化,STEP 4 三軸及部分判別閾值為製作者自訂補充,均非法定核對表項目。
